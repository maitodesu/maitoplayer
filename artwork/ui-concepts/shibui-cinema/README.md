# Shibui Cinema

A static, dependency-free visual direction for Maito Player. Open `index.html` directly in a browser.

The concept prioritizes the video canvas, treats synchronized JP/EN subtitles as one readable unit, and moves dictionary/card actions into quiet contextual layers. Furigana uses a high-contrast ink plate plus outline for legibility over unpredictable footage. Noto Sans JP is the preferred subtitle face, with local Japanese system-font fallbacks when it is unavailable.

Prototype-only interactions: hover or focus a highlighted subtitle word, toggle play/pause, expand the optional card composer, and use “Keep word” to focus it. No external assets or network requests are used.
