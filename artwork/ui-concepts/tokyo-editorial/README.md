# Tokyo Editorial

A static, browser-previewable UI direction for Maito Video. It combines a Japanese editorial grid with restrained paper, ink, and vermilion colors while keeping the video and dual-language subtitles primary.

Open `index.html` directly in a browser. No build, network access, or external assets are required.

The concept demonstrates:

- JP and EN cue pairing, with hiragana furigana set in `Noto Sans JP` when installed.
- A high-contrast subtitle plate designed for bright and detailed footage.
- An anchored dictionary result and optional word-card composer.
- Playback, navigation, subtitle-sync status, and responsive desktop/mobile layouts.

This is an exploratory prototype only; it does not modify the production application.
