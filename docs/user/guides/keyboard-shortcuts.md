# Keyboard shortcuts

Shortcuts work while focus is outside a form field, slider, subtitle token, or
unrelated control so that normal keyboard interaction is not intercepted. In
fullscreen, media shortcuts take priority over a focused player button; for
example, Space pauses instead of reactivating the Fullscreen button.

| Key | Action |
|---|---|
| Space or K | Play or pause |
| Left arrow | Seek backward five seconds |
| Right arrow | Seek forward five seconds |
| M | Mute or restore volume |
| F | Enter or leave player fullscreen |
| J | Show or hide Japanese subtitles |
| R | Show or hide furigana |
| E | Show or hide English subtitles |

Use Tab and Shift+Tab to move through the player, subtitle tokens, dictionary,
card composer, Settings, and Diagnostics. Enter or Space activates the focused
button. The timeline, volume, playback-rate, and audio-track controls use native
HTML controls and their operating-system keyboard behavior. Subtitle visibility
keys are persisted independently.

If a global shortcut appears unresponsive, move focus out of the currently
edited input. Do not disable visible focus indicators in Windows or the app.
