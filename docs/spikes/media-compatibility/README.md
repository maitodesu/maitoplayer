# Media compatibility spike

The fixture generator creates only synthetic color bars, test patterns, tones,
and authored subtitle text. Generated media is intentionally ignored by Git; the
script records local hashes and normalized probe evidence.

Run on Windows:

```powershell
./tools/media-fixtures/generate.ps1 -Ffmpeg C:/path/to/ffmpeg.exe -Ffprobe C:/path/to/ffprobe.exe
```

Then record WebView2 results in `support-matrix.md`. A class must not be promoted
to “verified” until first frame, audio, range seek, pause/resume, playback rate,
frame callback, canvas release, working-set plateau, and fallback cleanup have
all been observed on the named reference environment.

The application range protocol caps every response at 8 MiB. This is a structural
guard against copying an entire large source through Rust or JavaScript, but the
packaged development-app memory observation remains a release gate.
